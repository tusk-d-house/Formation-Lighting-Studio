# Formation & Lighting Studio

ダンスやステージパフォーマンスのための **2Dフォーメーション設計・3D照明演出・音楽同期タイムライン** を1つにまとめたWindows向けデスクトップアプリケーションです。

---

## 主な機能

### 1. フォーメーション設計（2Dステージ編集）
- **直感的な配置・移動**: 2Dステージ上でダンサーをドラッグ＆ドロップで配置（グリッドスナップ対応）
- **複数選択＆一括操作**: ドラッグによる範囲選択、`Shift` + クリックでの複数選択、複数人同時の移動・整列
- **フォーメーション間コピー＆ペースト**: 選択中のメンバーの形状・座標を `Ctrl+C` でコピーし、別フォーメーションへ `Ctrl+V` でそのままペースト
- **反転機能**: 位置のみ反転／ダンサーごと上下左右反転に対応
- **移動経路（パス）表示**: 前のフォーメーションからの移動軌跡を矢印・点線で可視化
- **出演ステータス管理**: ダンサーごとのカラー設定（グレー＝非出演、それ以外の色＝出演中）

### 2. 3Dステージ＆照明シミュレーション
- **リアルタイム3Dプレビュー**: Three.js（`@react-three/fiber`）によるボリューメトリックなビーム表現・床面照射シミュレーション
- **多彩な灯体グループ**:
  - ムービングライト（サス・フロア等）
  - シーリングライト、フロントライト、サイドライト（SS）、バックフット、アッパーホリゾント、ロアーホリゾント等
- **パン・チルトのモーション演出**:
  - サークル（円運動）、8の字、パンのみ、チルトのみなどの動きパターン
  - スピード、振れ幅、基準位相、**灯体間の同期ずらし（位相差）**、逆回転、左右対称ミラー動作に対応
- **ゴボ（Robe Pointe 準拠）**:
  - R-Gobo（2, 4, 6, 7）および S-Gobo（1, 3, 4, 7, 12, 14）の照射パターンとゴボ回転スピード設定
- **ストロボ演出**:
  - **BPM数値指定** またはスライダーによる速度調整
  - 矩形波、正弦波、ノコギリ波（傾き正／負）、三角波の波形選択
  - オン・オフのタイミング反転（Invert）機能
- **照明プリセット間コピー＆ペースト**:
  - サイドフットなどの特定照明グループや個別灯体の設定を `Ctrl+C` でコピーし、他の照明プリセットへ `Ctrl+V` で一括適用

### 3. 音楽同期タイムライン（0.01秒単位）
- **音声波形表示＆自動保存**: 音楽ファイル（MP3 / WAV 等）を読み込むと波形を自動描画し、プロジェクトごとにアプリ内に自動保存
- **0.01秒単位の精密エディット**: フォーメーションキュー・照明キューの開始時間および終了時間を `0.01秒` 単位で指定可能
- **スムーズな補間アニメーション**: キュー間の移動や照明フェード、パン・チルト移行をリアルタイムに補間再生
- **ピン（マーカー）機能**: 楽曲のカウントや展開位置にピンを打って素早く頭出し

### 4. キューシート＆出演表（Excel）出力
- **キューシート表示・印刷用ビュー**: 配置キュー・照明キューの時系列一覧と2Dステージプレビューを一覧表示
- **出演表（香盤表）Excel出力（`.xlsx`）**:
  - 各ダンサーがどのフォーメーションに出演しているかをチェックボックス（`TRUE` / `FALSE`）付きで自動集計
  - フォーメーションごとの出演合計人数やダンサー別の出演カウント数計算式も自動で組み込み

## キーボードショートカット

| キー | 動作 |
| :--- | :--- |
| `Space` | タイムラインの再生 / 一時停止 |
| `0` / `Home` | 再生位置を先頭（0秒）に戻す |
| `1` / `2` / `3` / `4` | モード切替（1: 配置 / 2: 照明 / 3: タイムライン / 4: 設定） |
| `V` | ビュー表示切替（2D+3D分割 / 2Dのみ / 3Dのみ） |
| `G` | グリッドスナップの ON / OFF |
| `Ctrl + S` | プロジェクトの上書き保存 |
| `Ctrl + Z` / `Ctrl + Y` | 元に戻す（Undo） / やり直す（Redo） |
| `Ctrl + C` / `Ctrl + V` | 選択ダンサーの配置コピー＆ペースト（配置画面）<br>選択照明グループ・灯体の設定コピー＆ペースト（照明画面） |
| `Ctrl + D` | 現在のフォーメーション／照明プリセットを複製 |
| `N` | 新規フォーメーション／照明プリセット／キューの追加 |
| `P` | 現在の再生位置にタイムラインピンを追加 |
| `[` / `]` | 前／次のフォーメーション（または照明プリセット）へ切替 |
| `矢印キー` | 選択ダンサーの微調整移動（配置画面）／再生位置の移動（タイムライン画面） |

## ダウンロード・起動方法（Windows）

ターミナルやNode.jsのインストールは不要です。一般的なWindowsアプリケーションとして起動できます。

1. 本リポジトリ右側の **[Releases](../../releases)** ページから最新の **`FormationStudio-Windows.zip`** をダウンロードします。
2. ダウンロードしたZIPファイルを任意の場所に**すべて展開（解凍）**します。
3. フォルダ内の **`FormationStudio.exe`** をダブルクリックするとアプリが起動します。
   - 💡 **デスクトップから起動したい場合**: `FormationStudio.exe` を右クリック ＞ **「送る」** ＞ **「デスクトップ（ショートカットを作成）」** を選ぶと、次回からデスクトップのアイコンをダブルクリックするだけで起動できます。

## 技術スタック

- **UI / フロントエンド**: React 18 / TypeScript / Vite / Tailwind CSS
- **3Dグラフィックス**: Three.js / `@react-three/fiber` / `@react-three/drei`
- **状態管理**: Zustand
- **アイコン**: Lucide React
- **デスクトップアプリ基盤**: Electron

---

## 開発者向け（ソースコードからビルド・起動する場合）

ソースコードを編集して開発環境で動かす場合は、[Node.js](https://nodejs.org/)（v18 以上）が必要です。

```bash
# 依存パッケージのインストール
npm install

# 開発モードで起動
npm run electron:dev

# 本番ビルド
npm run build
```
