# Formation Studio

ダンスやステージパフォーマンスのための、フォーメーション設計・3D照明演出・音楽同期タイムラインを1つにまとめたスタジオアプリです。

## 主な機能
- **2Dフォーメーション編集**: ステージ上のメンバー配置・移動経路の確認・反転・範囲コピー＆ペースト
- **3Dステージ＆照明シミュレーション**: Three.jsによるリアルタイム3Dプレビュー、パン・チルトの動き、ゴボ、ストロボ（BPM連動・各種波形）の演出設定
- **音源同期タイムライン**: 音声波形を見ながら0.01秒単位でフォーメーションや照明プリセットのキューを配置・再生
- **キューシート・Excel出力**: タイムラインのキューシート表示や、ダンサーの出演状況を確認できるExcelシートの出力
- **Web / デスクトップ両対応**: ブラウザ上でもElectronデスクトップアプリとしても動作

## 技術スタック
- React / TypeScript / Vite / Tailwind CSS
- Three.js (`@react-three/fiber`, `@react-three/drei`)
- Zustand
- Electron
